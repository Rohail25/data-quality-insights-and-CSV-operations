Sales Data Analysis and CSV Manipulation Project
Project Overview

This project focuses on sales data analysis, data quality improvement, basic business insights, and CSV file manipulation using Python.

The project is divided into two parts:

Part A: Data Quality & Basic Insights (70 Marks)
Part B: CSV File Handling & Manipulation (30 Marks)

The main objective is to transform raw sales data into a clean and structured dataset, analyze sales performance, visualize important findings, and perform additional modifications to the cleaned CSV file.

Only the following Python libraries are used:

Pandas: For reading, cleaning, modifying, grouping, and exporting CSV data.
NumPy: For numerical data handling and calculations.
Matplotlib: For creating charts and visualizing sales information.
Part A: Data Quality & Basic Insights
1. Loading and Inspecting the Dataset

The project starts by loading the original sales_raw.csv file using Pandas.

The dataset is inspected to understand its structure and identify potential data quality problems.

The following functions are used:

pd.read_csv() – Loads the CSV file.
head() – Displays the first five records.
shape – Shows the number of rows and columns.
columns – Displays all column names.
dtypes – Identifies the data type of each column.
isna().sum() – Counts missing values in each column.
duplicated().sum() – Counts duplicate records.

This inspection helps identify missing information, repeated records, and inconsistencies before performing data analysis.

2. Cleaning the Dataset

A separate copy of the original dataset is created to preserve the original input file.

Several cleaning operations are performed.

Text Standardization

Extra spaces are removed from the region and category columns using str.strip().

Inconsistent capitalization is standardized using str.title().

For example:

" north " becomes "North".
"ELECTRONICS" becomes "Electronics".
" furniture " becomes "Furniture".
Handling Missing Values

Rows containing missing essential information are removed using dropna().

The essential columns include:

Region
Category
Quantity
Unit Price

These columns are necessary for reliable sales calculations and analysis.

Handling Invalid Numerical Values

The quantity and unit_price columns are converted into numerical data using pd.to_numeric().

Invalid numerical entries are converted into missing values and removed.

Rows with zero or negative quantities and prices are also removed because they do not represent valid positive sales transactions under the project's cleaning rules.

Removing Duplicate Records

Duplicate rows are removed using drop_duplicates().

This prevents repeated sales records from incorrectly increasing the total revenue.

Comparing Dataset Size

The original row count is compared with the cleaned row count.

This identifies how many records were removed during the cleaning process.

The original sales_raw.csv file remains unchanged.

3. Calculating Sales Revenue

A new column named revenue is added to the cleaned dataset.

Revenue is calculated using the following formula:

Revenue = Quantity × Unit Price

This calculation determines the total sales value of each transaction.

4. Grouping and Summarizing Data

The Pandas groupby() function is used to summarize total revenue.

Two summaries are generated:

Revenue by Region
Revenue by Category

These summaries help identify which regions and product categories contribute the most to total sales.

5. Creating Visualizations

Two charts are created using Matplotlib.

Chart 1: Revenue by Region

This bar chart displays the total revenue generated by each region.

It helps compare regional sales performance and identify the highest-revenue region.

Chart 2: Revenue by Category

This bar chart displays the total revenue generated by each product category.

It helps identify the best-performing product category.

Both charts include:

Descriptive titles
X-axis labels
Y-axis labels
Different bar colors
Grid lines for easier comparison

The charts are saved as PNG files.
